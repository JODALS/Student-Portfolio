
# Student Portfolio Website 🚀

A personal portfolio website built as part of **Class 11 – Builders Day** at Scaler School of Technology. This project showcases my skills, education, projects, and learning journey as a Computer Science student.

The website is designed to be clean, responsive, and easy to navigate while demonstrating the core concepts of HTML and CSS learned during the Web Development course.

## ✨ Features

- Personal introduction and hero section
- About Me section
- Technical skills showcase
- Projects section with descriptions
- Education section
- Contact section with relevant links
- Responsive layout for different screen sizes
- CSS transitions, hover effects, and animations
- Layouts using Flexbox and CSS Grid

## 🛠️ Technologies Used

- HTML5 — Website structure and semantic elements
- CSS3 — Styling, layouts, responsive design, and animations

## 📂 Projects Featured

### 1. Spotify Clone
A music-streaming interface inspired by Spotify, created to practice web development and recreate a familiar user interface.

### 2. Clear the Clutter
A command-line tool built using Python to organize files and reduce clutter, demonstrating programming and file-handling concepts.

### 3. College Assignment 1
A project completed as part of college coursework to apply programming and technical concepts.

### 4. College Assignment 2
Another coursework project showcasing the skills and concepts developed during my learning journey.

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the downloaded project folder.
3. Open `index.html` in your web browser.

No backend or JavaScript setup is required.
